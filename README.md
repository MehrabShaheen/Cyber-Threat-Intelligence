# Cyber-Threat-Intelligence

## Overview

This repository documents my hands-on experience with Cyber Threat Intelligence (CTI) using MISP and OpenCTI. The lab focuses on collecting, organizing, correlating, and analyzing threat intelligence to improve threat detection and incident response. It demonstrates how threat intelligence platforms help security teams manage Indicators of Compromise (IOCs), track adversary activities, and share actionable intelligence.

## Objectives

* Deploy and explore Cyber Threat Intelligence platforms.
* Manage and analyze Indicators of Compromise (IOCs).
* Understand threat intelligence lifecycle and intelligence sharing.
* Correlate threat data to support security investigations.
* Enhance threat detection through contextual intelligence.

## Activities Performed

* IOC management (IP addresses, domains, URLs, file hashes)
* Threat intelligence collection and organization
* Threat correlation and relationship mapping
* Analysis of threat actors, malware, campaigns, and indicators
* Event creation and intelligence sharing in MISP
* Knowledge graph exploration in OpenCTI
* Mapping threats to the MITRE ATT&CK framework

## Skills Demonstrated

* Cyber Threat Intelligence (CTI)
* IOC Analysis
* Threat Hunting Support
* Threat Intelligence Correlation
* Intelligence Sharing
* Threat Actor Profiling
* Malware & Campaign Analysis
* Security Investigation
* MITRE ATT&CK Mapping


## Learning Outcomes

This project strengthened my understanding of Cyber Threat Intelligence workflows, IOC management, threat correlation, and intelligence-driven security operations using industry-standard CTI platforms.
